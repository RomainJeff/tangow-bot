P3 reproduction sheet

Requirements: Node 24 and pnpm 9.15.0 on the build machine, Docker for the PostgreSQL harness. The live
lanes need an E2B deployment with I1's volumes and its computer template, an API key for it, and Node 22
or later where they run. No model key: the model is the repository's emulator on loopback.
Start from a clean checkout of the P3 slice.

Setup
  pnpm install --frozen-lockfile
  pnpm db:generate

Checks
  pnpm check
  pnpm lint

The P3 offline tests this slice touches
  pnpm exec vitest run packages/testkit/src/runtime-worker packages/adapters/src/e2b-volume-files.test.ts packages/adapters/src/e2b-worker.test.ts

Integration
  pnpm test:integration

Live lanes, where the E2B API is reachable
  Export the E2B environment to the command only: E2B_API_KEY, and E2B_API_URL with E2B_SANDBOX_URL,
  or E2B_DOMAIN.
  pnpm --filter @rakazo/agent-run-worker template:build --name <worker template>
  pnpm test:worker-live lanes --template <worker template> --computer-template <computer template> --out <dir>
  pnpm test:worker-live bench --template <worker template> --computer-template <computer template> --out <dir> --trials 30

Live lanes on a host with no checkout, as these receipts were produced
  1. On the build machine: pnpm test:worker-live:bundle
     It writes packages/testkit/dist/worker-live/ (bin/worker-live.mjs for Node 22 with PGlite's assets,
     prisma/migrations, guest/agent-run-worker.mjs, and guest/hostile-guest.mjs for lane e-refusals).
  2. Copy that directory to a scratch directory on the host. Copy nothing else: no checkout, no .env.
  3. On the host, with the E2B environment exported to each command only (the receipts used I1's
     with-e2b.sh, which reads the team key from the stack and passes it to the command):
       node live/bin/worker-live.mjs template --guest live/guest/agent-run-worker.mjs --name <worker template>
       node --expose-gc live/bin/worker-live.mjs lanes --template <worker template> --computer-template <computer template> --out out
       node --expose-gc live/bin/worker-live.mjs bench --template <worker template> --computer-template <computer template> --out out --trials 30
  4. Remove the scratch directory when done.

Safety rails built into the lanes
  Each lane runs in its own process, one at a time. Before each lane the command stops if any sandbox runs
  on the deployment or if the host's MemAvailable is under 1,536 MiB. Every sandbox carries the
  session's p3live tag, and the session records the name of every volume it creates. Each lane ends with a sweep that kills and
  destroys everything of its session, then counts what is left. The receipts are redacted: no key,
  endpoint, address other than loopback, account, machine name or local path.
