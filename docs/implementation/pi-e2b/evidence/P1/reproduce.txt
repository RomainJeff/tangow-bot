P1 reproduction sheet

Requirements: Node 24, pnpm 9.15.0, Docker for the PostgreSQL harness and the web E2E suite. No vendor credentials.
Start from a clean checkout of the P1 slice.

Setup
  pnpm install --frozen-lockfile
  pnpm db:generate

Checks
  pnpm check
  pnpm lint
  pnpm --filter @rakazo/adapter-kit check
  pnpm --filter @rakazo/adapters check

Lane tests on PGlite with every migration (lanes 1 and 3 to 10)
  pnpm exec vitest run packages/core/src/worker-plan.test.ts packages/adapter-kit/src/worker-protocol.test.ts packages/adapters/src/worker-lifecycle.test.ts packages/adapters/src/worker-volumes.test.ts packages/adapters/src/worker-migration.test.ts packages/adapters/src/computer-workspace.test.ts

Lane 2 races and the full PostgreSQL journeys (Testcontainers PostgreSQL 16)
  pnpm test:integration
  The harness runs packages/adapters/src/worker-lifecycle.postgres.test.ts as its last suite.

One lane, for example lane 3
  pnpm exec vitest run packages/adapters/src/worker-lifecycle.test.ts -t "private_volume_of_other_bot"

Plan resolution and start-release probe
  pnpm bench:worker-plan --out worker-plan-bench.json

Common path, alternating trunk and head
  Create a second checkout of the feature base (af6940d24) and install it, then run 30 trials.
  Odd trials run trunk first, even trials run head first. Each sample is a fresh process.
    pnpm exec tsx docs/implementation/pi-e2b/evidence/P1/common-path-probe.ts <trunk checkout> trunk 50
    pnpm exec tsx docs/implementation/pi-e2b/evidence/P1/common-path-probe.ts . head 50

Web E2E
  pnpm test:e2e:affected
