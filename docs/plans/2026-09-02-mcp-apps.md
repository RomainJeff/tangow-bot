# MCP Apps (interactive widgets in threads) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** When an MCP tool declares a UI resource (MCP Apps, SEP-1865), Rakazo renders that HTML widget inside the thread instead of only the JSON tool result.

**Architecture:** The MCP connector (`packages/adapters/src/mcp-connector.ts`) already talks to remote MCP servers through `McpSession`. We (1) advertise the `io.modelcontextprotocol/ui` client capability, (2) keep tool `_meta.ui.resourceUri`, (3) after a tool call, read the `ui://` resource and yield a new `app` connector event, (4) the executor stores the HTML as an artifact and publishes a new `mcp_app` message block, (5) the web client renders the block in a sandboxed `srcdoc` iframe and drives it with `AppBridge` from `@modelcontextprotocol/ext-apps`. Phase 1 is display-only (tool input + result pushed to the widget, links, auto-height). Phase 2 adds widget → server tool calls and widget → chat messages. Phase 3 is backlog.

**Tech Stack:** TypeScript pnpm monorepo, vitest, zod 4, `@modelcontextprotocol/sdk` 1.30.0 (already in `@rakazo/adapters`), `@modelcontextprotocol/ext-apps` 1.7.5 (new, web only), React 19, Lingui.

## Findings from exploration (read before starting)

**Spec facts (MCP Apps, `@modelcontextprotocol/ext-apps` 1.7.5):**
- Client advertises `capabilities.extensions["io.modelcontextprotocol/ui"] = { mimeTypes: ["text/html;profile=mcp-app"] }`.
- Tool declares `_meta.ui.resourceUri: "ui://…"`; optional `_meta.ui.visibility: ("model"|"app")[]` (absent = model-visible). Legacy key `_meta["ui/resourceUri"]` exists in older servers; ChatGPT-only `openai/outputTemplate` is out of scope.
- `resources/read` returns `contents[0]` with `mimeType: "text/html;profile=mcp-app"`, `text` = HTML, `_meta.ui` = `{ csp?: { connectDomains?, resourceDomains?, frameDomains?, baseUriDomains? }, permissions?: { camera?, microphone?, geolocation?, clipboardWrite? }, prefersBorder?, domain? }`.
- Host side API (`@modelcontextprotocol/ext-apps/app-bridge`): `new AppBridge(client | null, hostInfo, hostCapabilities, { hostContext })`, callbacks `oninitialized`, `onmessage`, `onopenlink`, `onsizechange`, `onrequestdisplaymode`, `onupdatemodelcontext`, `oncalltool`; sends `sendToolInput({ arguments })`, `sendToolResult(result)`; `connect(new PostMessageTransport(iframe.contentWindow, iframe.contentWindow))`; `buildAllowAttribute(permissions)` builds the iframe `allow` attribute. No CSP string helper in the SDK; host builds it.
- The app SDK posts `ui/initialize` to `window.parent`. The reference "sandbox proxy" (double iframe on a separate origin) is NOT required; a sandboxed `srcdoc` iframe with a `<meta http-equiv="Content-Security-Policy">` works and is stricter (opaque origin, no `allow-same-origin`).

**Rakazo seams verified:**
- `McpSession` (`packages/adapters/src/mcp-transport.ts:226`) has `listTools`, `callTool`, no `readResource`. `McpClientOptions.capabilities` is `ConstructorParameters<typeof Client>[1]` (the SDK `ClientOptions`), not yet passed by `McpConnector.connectSession` (`mcp-connector.ts:258`).
- `McpConnector.authorizedTools` (`mcp-connector.ts:106-148`) drops `_meta`. `execute` (`:150-205`) yields `{ type: "result", data: result }`.
- `ConnectorTool` / `ConnectorEvent` live in `packages/adapter-kit/src/types.ts:169-198`.
- Executor connector branch `packages/adapters/src/executor.ts:2685-2706` is the only consumer of connector events; `publishMessage(deps, run, "bot", blocks)` at `:3677`; `render_plot` shows the artifact + publish pattern at `:1889-1911`.
- `attachWorkspaceFileToThread` (`packages/adapters/src/thread-artifacts.ts:42-107`) validates mime via the attachment allowlist (`packages/contracts/src/attachments.ts`) which rejects `text/html`. We extract the lower-level store step.
- `MessageBlock` discriminated union `packages/contracts/src/events.ts:84-246`; web renders blocks in `MessageView` switch `apps/web/src/pages/Shell.tsx:5219-5495` (`chart` branch `:5383`, `ChartBlockView` `:6973`). `fetchArtifactBytes(target, artifactId)` in `apps/web/src/lib/artifact-open.ts`.
- Mobile: unknown block kinds render nothing (`apps/mobile/app/thread.tsx` `MessageTextCard` returns `null` when no text). Safe to ship web-only.
- Pi runtime only sees `tool.inputSchema`; `meta` on `ConnectorTool` never reaches the model.

**Composio / Pipedream verdict:** Composio (Tool Router, Rube, custom MCP) and Pipedream Connect expose tools only. No `_meta.ui`, no widget resources. Widgets require servers that implement MCP Apps (our own or third-party). Nothing to do on the Composio connector.

**Ponytail decisions:**
- `srcdoc` + `sandbox="allow-scripts allow-forms"` instead of a proxy origin. Ceiling: widgets that need `allow-same-origin` (cookies, storage). Upgrade path: Phase 3 proxy origin.
- Phase 1 does not advertise `serverTools`; `oncalltool` is Phase 2.
- Tool result stored in the block is capped (24 000 chars serialized) to keep messages small; the widget gets the capped payload.
- One `app` event per tool call; `resources/read` failure logs and falls back to the plain result (never breaks the run).

// packages/adapters/src/mcp-app.ts
// MCP Apps (SEP-1865) helpers shared by the MCP connector and the executor.

export const MCP_APP_MIME = "text/html;profile=mcp-app";
export const MCP_UI_EXTENSION = "io.modelcontextprotocol/ui";
/** Client capability advertised to MCP servers so they return `_meta.ui`. */
export const MCP_UI_CLIENT_CAPABILITIES = {
  extensions: { [MCP_UI_EXTENSION]: { mimeTypes: [MCP_APP_MIME] } },
} as const;
/** Serialized tool result kept in the message block for the widget. */
export const MCP_APP_MAX_RESULT_CHARS = 24_000;

type Meta = Record<string, unknown> | undefined;

function uiMeta(meta: Meta): Record<string, unknown> | undefined {
  const ui = meta?.ui;
  return ui && typeof ui === "object" ? (ui as Record<string, unknown>) : undefined;
}

export function appResourceUri(meta: Meta): string | undefined {
  const uri = uiMeta(meta)?.resourceUri ?? meta?.["ui/resourceUri"];
  return typeof uri === "string" && uri.startsWith("ui://") ? uri : undefined;
}

export function isModelVisibleTool(meta: Meta): boolean {
  const visibility = uiMeta(meta)?.visibility;
  return !Array.isArray(visibility) || visibility.includes("model");
}

export interface AppResource {
  html: string;
  csp?: Record<string, unknown>;
  permissions?: Record<string, unknown>;
  prefersBorder?: boolean;
}

export function appHtmlFromResource(read: {
  contents: Array<{ mimeType?: string; text?: string; _meta?: Record<string, unknown> }>;
  _meta?: Record<string, unknown>;
}): AppResource | undefined {
  const content = read.contents.find((c) => c.mimeType === MCP_APP_MIME && typeof c.text === "string");
  if (!content?.text) return undefined;
  const ui = uiMeta(content._meta) ?? uiMeta(read._meta) ?? {};
  return {
    html: content.text,
    csp: ui.csp as Record<string, unknown> | undefined,
    permissions: ui.permissions as Record<string, unknown> | undefined,
    prefersBorder: typeof ui.prefersBorder === "boolean" ? ui.prefersBorder : undefined,
  };
}

export function stripToolMeta<T extends { _meta?: unknown }>(result: T): Omit<T, "_meta"> {
  const { _meta: _ignored, ...rest } = result;
  return rest;
}

// ponytail: cap by dropping content past the limit; widgets needing full payloads should fetch via Phase 2 tool calls.
export function capToolResult(result: unknown): unknown {
  if (JSON.stringify(result).length <= MCP_APP_MAX_RESULT_CHARS) return result;
  const content = Array.isArray((result as { content?: unknown[] })?.content)
    ? (result as { content: unknown[] }).content
    : [];
  const kept: unknown[] = [];
  let size = 0;
  for (const block of content) {
    size += JSON.stringify(block).length;
    if (size > MCP_APP_MAX_RESULT_CHARS) break;
    kept.push(block);
  }
  return { ...(result as object), content: kept, truncated: true };
}
```

// apps/web/src/lib/mcp-app.ts
// Content-Security-Policy for MCP App iframes, per the MCP Apps spec (SEP-1865).

export interface McpAppCsp {
  connectDomains?: string[];
  resourceDomains?: string[];
  frameDomains?: string[];
  baseUriDomains?: string[];
}

const httpsOnly = (domains?: unknown) =>
  (Array.isArray(domains) ? domains : []).filter(
    (d): d is string => typeof d === "string" && /^https:\/\/[^\s'";]+$/.test(d),
  );

export function mcpAppCsp(csp: McpAppCsp | Record<string, unknown> | undefined): string {
  const c = (csp ?? {}) as McpAppCsp;
  const resources = httpsOnly(c.resourceDomains).join(" ");
  const connect = httpsOnly(c.connectDomains).join(" ");
  const frames = httpsOnly(c.frameDomains).join(" ") || "'none'";
  const base = httpsOnly(c.baseUriDomains).join(" ") || "'self'";
  const join = (...parts: string[]) => parts.filter(Boolean).join(" ");
  return [
    "default-src 'none'",
    join("script-src 'self' 'unsafe-inline'", resources),
    join("style-src 'self' 'unsafe-inline'", resources),
    join("img-src 'self' data:", resources),
    join("font-src 'self'", resources),
    join("media-src 'self' data:", resources),
    join("connect-src 'self'", connect),
    `frame-src ${frames}`,
    "object-src 'none'",
    `base-uri ${base}`,
  ].join("; ") + ";";
}

/** Prepend a CSP meta tag so it applies before any script in the widget HTML. */
export function mcpAppSrcdoc(html: string, csp: string): string {
  const meta = `<meta http-equiv="Content-Security-Policy" content="${csp.replace(/"/g, "&quot;")}">`;
  const head = html.match(/<head[^>]*>/i);
  if (head?.index !== undefined) {
    const at = head.index + head[0].length;
    return html.slice(0, at) + meta + html.slice(at);
  }
  return `<head>${meta}</head>${html}`;
}
```

type McpAppBlock = Extract<MessageBlock, { kind: "mcp_app" }>;

const MIN_HEIGHT = 120;
const MAX_HEIGHT = 900;

export function McpAppBlockView({ target, block }: { target: ArtifactTarget; block: McpAppBlock }) {
  const iframeRef = useRef<HTMLIFrameElement | null>(null);
  const [srcdoc, setSrcdoc] = useState<string | null>(null);
  const [height, setHeight] = useState(MIN_HEIGHT);
  const [failed, setFailed] = useState(false);

  useEffect(() => {
    let cancelled = false;
    fetchArtifactBytes(target, block.artifactId)
      .then((bytes) => {
        if (!cancelled) setSrcdoc(mcpAppSrcdoc(new TextDecoder().decode(bytes), mcpAppCsp(block.csp)));

      cancelled = true;

      { openLinks: {} },
      {
        hostContext: {
          theme: "dark",
          platform: "web",
          displayMode: "inline",
          availableDisplayModes: ["inline"],
          containerDimensions: { maxHeight: MAX_HEIGHT },
          locale: navigator.language,
        },
      },

      bridge.sendToolResult(block.toolResult as Parameters<typeof bridge.sendToolResult>[0]);
    };
    bridge.onopenlink = async ({ url }) => {
      if (/^https?:\/\//.test(url)) window.open(url, "_blank", "noopener,noreferrer");

      if (typeof next === "number") setHeight(Math.min(MAX_HEIGHT, Math.max(MIN_HEIGHT, Math.ceil(next))));

    bridge.connect(new PostMessageTransport(win, win));
    bridgeRef.current = bridge;
  };

  const bridgeRef = useRef<AppBridge | null>(null);
  useEffect(() => () => void bridgeRef.current?.close?.(), []);

  if (failed) {
    return (
      <div className="max-w-[74%] rounded-[20px] bg-[#17171A] p-4 text-sm text-white/60">
        <Trans>Widget unavailable</Trans>
      </div>
    );
  }
  if (srcdoc === null) return <div className="h-[120px] max-w-[74%] animate-pulse rounded-[20px] bg-[#17171A]" />;

  );
}
